# NIST Cybersecurity Framework (CSF) 2.0 — Feb 2024

- **6 Functions:** **Govern** (new in 2.0), Identify, Protect, Detect, Respond, Recover.
- **22 categories, 106 subcategories.** Strategic/outcome-oriented (the "what").
- Voluntary; widely used as a program backbone. Maps down to 800-53 r5 for the "how".
